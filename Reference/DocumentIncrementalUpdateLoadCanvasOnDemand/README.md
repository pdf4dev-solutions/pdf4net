The incremental update mode gives you the possibility to partially load a PDF file in memory, for faster loads and reduced memory usage. This mode makes posible to load only pages information without loading the actual page content if operations on page content are not required.

But sometimes you might need to process the content for some pages and you do not want to load the content for all pages in the document. For this scenario we introduced the possibility to load the page content on demand. You have the option to load the minimal structures if you only want to add new content to the page or load the full page content if you want to do some processing on it (text extraction and search, redaction, etc).
The new `PdfPage.LoadGraphics(bool enableAllOperatins)` lets you load the page content on demand. `true` parameter means full page content is loaded and all page content related operations are allowed, `false` means only minimal structures and loaded and only adding new page content is supported.
